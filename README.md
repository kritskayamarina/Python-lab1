# Лабораторная работа 1. Сбор параметров ОС.

Результатом работы является скрипт, определяющий в какой операционной системе он запускается и собирающий её параметры в файл формата JSON. В скрипте используются только стандартные модули Python: 
platform, os, socket, getpass, shutil, с помощью которых производится сбор следующих данных: операционная система, серсия операционной системы, релиз операционной системы, процессор, память на диске (вся, свободная, занятая), имя устройства, имя пользователя и версия Python. Далее собранные данные записываются в файл с помощью модуля json.
