# Лабораторная работа 1. Сбор параметров ОС.

Результатом работы является скрипт, определяющий в какой операционной системе он запускается и собирающий её параметры в файл формата JSON. В скрипте используются только стандартные модули Python: 
platform, os, socket, getpass, shutil, с помощью которых производится сбор следующих данных: 
1. Операционная система
2. Серсия операционной системы
3. Релиз операционной системы
4. Процессор
5. Память на диске 
6. Свободная память на диске
7. Занятая память на диске
8. Имя устройства
9. Имя пользователя
10. Версия Python.
 
Далее собранные данные записываются в файл с помощью модуля json, а также появляются в строке вывода для удобства.
